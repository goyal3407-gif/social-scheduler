# Android app

The KiluaAI Android app lives in its **own repository**:
**goyal3407-gif/goyal-kumar-scheduler-android** (local checkout:
`~/workspace/goyal-kumar-scheduler-android`).

It is a Capacitor shell that loads this web app's live URL, so all UI and
features — including the mobile app-style layout and the Media Library's
"On this device" video storage (`frontend/src/localMedia.js`) — are built
and deployed from this repo. The Android repo holds only the native
wrapper, its build notes, and copies of the legal pages.
